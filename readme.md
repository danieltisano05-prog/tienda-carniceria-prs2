# Tienda Carnicería

Proyecto de e-commerce desarrollado para la materia Aplicaciones Web 1.

La aplicación representa una tienda online para una carnicería, 
donde los usuarios podrán consultar productos de distintas categorías, 
registrarse, iniciar sesión y utilizar un carrito de compras.

## Categorías

- Carne vacuna
- Cerdo
- Pollo
- Elaborados
